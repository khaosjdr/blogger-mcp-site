Blogger MCP

Blogger MCP は、開発者本人が自分の Blogger ブログを AI アシスタント（MCP クライアント）から読み書きするための個人用ツールです。一般向けのサービスではありません。

Blogger MCP is a personal tool that lets its developer read and write their own Blogger blog from an AI assistant (MCP client). It is not offered as a public service.
