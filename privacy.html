プライバシーポリシー

最終更新: 2026-11-24

  • Blogger MCP は、利用者の PC 上で動作する個人用ツールです。
  • Google アカウントの認可（スコープ: https://www.googleapis.com/auth/blogger）は、利用者自身のブログの記事一覧の取得・記事の取得・記事の作成のためにだけ使います。
  • 取得したデータと認証トークンは利用者の PC にのみ保存され、開発者や第三者のサーバーには送信しません。データの販売・共有・広告利用は行いません。
  • 利用者は Google アカウントの「サードパーティによるアクセス」設定からいつでもアクセス権を取り消せます。

Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

Privacy Policy

  • Blogger MCP is a personal tool that runs on the user's own computer.
  • Google authorization (scope: https://www.googleapis.com/auth/blogger) is used only to list, read and create posts on the user's own blogs.
  • Retrieved data and tokens are stored only on the user's computer and are never sent to the developer or any third party. Data is not sold, shared or used for advertising.
  • Access can be revoked at any time from the Google Account "Third-party access" settings.

Blogger MCP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
